# jelly-munch
Welcome to my very first game ever! Play as Munchy, a slime catching fruits falling from the sky! Move around and catch as many fruits as you can. Made with Godot 4.7.2, this little project is my first step into game development. There may be bugs, but I'm proud to share it. Thanks for playing!

How to run: 
- Download zip file from releases 
- Extract zip file 
- Run "Jelly Munch"

For Windows only
